CSV Preparation & Downloadable Sample Files

CloudTrim natively accepts official exports from Microsoft 365 Admin Center, Azure Cost Management, or our local PowerShell collector.

Microsoft 365 ActiveUsers.csv

How to obtain: M365 Admin Center > Users > Active users > Export users. Or run: Get-MgUser -All | Export-Csv

Required Columns: UserPrincipalName, AccountEnabled (or Block credential), AssignedLicenses, LastSignInDateTime
⬇ Download Sample M365 CSV

Azure Cost & Resource CSV

How to obtain: Azure Portal > Cost Management > Cost analysis > Export. Or run Export-CloudTrimData.ps1

Required Columns: ResourceId, ResourceType, ResourceGroup, PreTaxCostUSD, DiskState / ManagedBy

              Architecture & Execution Specification:
              

                • Execution Location: Runs locally on your administrative workstation or jumpbox via Windows Task Scheduler.

                • Host Availability: The host computer must be powered on and connected to the internet at the scheduled time.

                • History Storage: Audit CSV snapshots are stored locally on your machine at C:\CloudTrim\History\.

                • Continuous Pro Entitlement: Provides monthly web diff comparison, automated rule and SKU updates, and email notifications.
