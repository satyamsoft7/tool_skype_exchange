CSV Preparation, Field Requirements & Tested Collectors

CloudTrim parses standard CSV exports entirely within your browser memory. Below are the tested export procedures and column classifications:

Microsoft 365 ActiveUsers.csv

Method 1 (GUI): M365 Admin Center > Users > Active users > click Export users.
Method 2 (PowerShell): Run the tested collector below to expand nested licenses & sign-ins: 
Connect-MgGraph -Scopes "User.Read.All","AuditLog.Read.All"
Get-MgUser -All -Property Id,DisplayName,UserPrincipalName,AccountEnabled,AssignedLicenses,SignInActivity |
  Select-Object DisplayName, UserPrincipalName, AccountEnabled,
    @{N="AssignedLicenses";E={($_.AssignedLicenses | ForEach-Object { $_.SkuId }) -join ";"}},
    @{N="LastSignInDateTime";E={$_.SignInActivity.LastSignInDateTime}} |
  Export-Csv -Path "ActiveUsers.csv" -NoTypeInformation -Encoding utf8
• Mandatory Required: UserPrincipalName (or User principal name), AccountEnabled (or Block credential), and AssignedLicenses (or Licenses / SKU).
• Optional: LastSignInDateTime (enables 90-day inactivity analysis; if absent, inactive check is marked unassessed), DisplayName, Department.

Azure Cost & Resource CSV

Method 1 (Portal): Azure Portal > Cost Management > Cost analysis > Export.
Method 2 (PowerShell): Run our unattached disk and idle compute collector: 
Connect-AzAccount
Get-AzDisk | Where-Object { $null -eq $_.ManagedBy } |
  Select-Object @{N="ResourceId";E={$_.Id}}, @{N="ResourceType";E={"Microsoft.Compute/disks"}},
    ResourceGroupName, Name, DiskSizeGB, Sku, DiskState |
  Export-Csv -Path "AzureDisks.csv" -NoTypeInformation -Encoding utf8
• Mandatory Required: ResourceId (or ResourceName/Name), ResourceType (or MeterCategory), ResourceGroup, PreTaxCostUSD (or Cost / SKU).
• Optional: DiskState, ManagedBy, Tags.
