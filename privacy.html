2. The Zero-Server Technical Architecture (How Your Data Is Handled)

Core Privacy Architecture — 100% In-Browser RAM Execution:
CloudTrim is architected from the ground up on strict data minimization principles. When you upload or drag-and-drop a Microsoft 365 ActiveUsers.csv or Azure Cost Management CSV file:
  • The file is parsed strictly inside your workstation's local web browser memory (RAM) via the native HTML5 File API.
  • Zero bytes of directory data are ever transmitted across the network to our servers, third-party databases, or cloud analytics backends.
  • No user emails, UserPrincipalNames (UPNs), employee display names, mailbox sizes, or Azure subscription IDs are ever uploaded, logged, or stored by us.

2.1 Instantaneous Erasure (No Persistent Storage)

Because all parsed data exists solely in volatile browser RAM, all session records, calculation objects, and identity findings are immediately and permanently destroyed the instant you refresh the webpage, navigate away, or close your browser tab. There are no server databases, cookies, or cloud storage buckets holding your customer or organization records.

2.2 No Tracking Cookies or Behavioral Profiling

We do not use advertising cookies, marketing pixels (such as Meta Pixel or Google Ads Remarketing), or cross-site behavioral fingerprinting scripts. The application does not profile administrators or sell data to data brokers.
