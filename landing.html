What CloudTrim Automatically Detects
Rigorous deterministic rules covering both M365 subscription entitlements and Azure cloud infrastructure.

Microsoft 365 License Inefficiencies

  • Critical
    Disabled Entra ID Accounts with Active Licenses: Staff offboarded in directory but retaining billed licenses ($38/mo E5, $23/mo E3).
  • High
    Over-Licensed Shared Mailboxes: Mailboxes under 50GB holding paid licenses when no Litigation Hold or Purview retention policy requires it.
  • Medium
    Inactive Licensed Users: Accounts with zero interactive sign-ins in 90+ days that qualify for license suspension or E1 downgrade.
  • Medium
    Redundant Standalone SKUs: Standalone add-ons (Exchange Online Plan 1/2) assigned to users already possessing bundled suites.

Azure Infrastructure Waste

  • Critical
    Unattached Managed Disks (Premium/Standard SSD): Disks retained after VM deletion still billing hourly storage at full rate.
  • High
    Empty App Service Plans: Dedicated compute instances (P1v2, S1) running 24/7 with zero hosted web apps or API containers.
  • Medium
    Unassociated Static Public IPs: Reserved IPv4 addresses not bound to any NIC, Load Balancer, or Virtual Network Gateway.
  • Verification
    Needs Verification State: Whenever cost exports lack attachment or lock status, assets are flagged for explicit confirmation.
